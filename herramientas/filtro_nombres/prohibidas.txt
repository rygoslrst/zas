# Palabras prohibidas en los nombres de la tabla de récords.
#
# Una por línea, escrita normal (con o sin tildes, da lo mismo). Al final:
#   *  sólo cuenta como palabra entera (para las cortas o comunes: ANO, WN)
#   ~  también cuenta escrita al revés, como palabra suelta (ATUP)
# Las que no tienen * se buscan dentro de las palabras (MIPENE) y de las
# palabras pegadas a otra corta (PU TA, MARI CON). Para palabras con género conviene la raíz (BOLUD atrapa BOLUDO y
# BOLUDA). No hace falta poner variantes de escritura (PUUTA, P3N3, KULO,
# XUXA, GÜEÓN, POYA): el filtro ya las lleva a la misma forma.
#
# "## tema" agrupa (queda como nota en Supabase).
# Después de cambiar algo: python herramientas/filtro_nombres/armar.py
# (actualiza js/filtroNombres.js y escribe sincronizar.sql para la base).
